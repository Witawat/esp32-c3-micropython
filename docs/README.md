ยินดีต้อนรับสู่คู่มือการใช้งาน **ESP32 MicroPython Framework** — ชุดไลบรารี (lib) สำหรับ ESP32 ทุกรุ่น (ESP32 / S2 / S3 / C3 / C6) ประกอบด้วยโมดูลสำเร็จรูปกว่า **95 โมดูล** ใน **29 หมวด** ครอบคลุมทุกฟังก์ชันสำหรับโปรเจกต์ IoT ตั้งแต่เซ็นเซอร์ จอแสดงผล การสื่อสาร ไปจนถึงระบบ Cloud และ Security

## วิธีใช้คู่มือนี้

- **เริ่มต้นใช้งาน** — วิธี deploy `lib/` ลงบอร์ดและตั้งค่า `sys.path`
- **หมวดแต่ละตัว** — แต่ละหน้าอธิบายเป็น 8 ส่วนมาตรฐาน: แนวคิดการใช้งาน, การติดตั้ง/import, constructor, ตาราง API (รับ/ส่งอะไร ใช้กับ method ไหน), ตัวอย่างโค้ด 3 ระดับ, การต่อวงจร, ข้อควรระวัง และ lib ที่ต้องใช้ร่วมกัน
- **ช่องค้นหา** ที่มุมขวาบน ใช้ค้นหาหมวด / คลาส / method ได้ทั้งเว็บ
- กดปุ่ม 🌙/☀️ เพื่อสลับธีมมืด/สว่าง

## หลักการสำคัญของเฟรมเวิร์ก

| หลักการ | คำอธิบาย |
|---|---|
| ⚡ Async-First | โมดูลที่ทำงาน I/O รองรับ `async/await` — รันงานหลายอย่างพร้อมกัน |
| ⚙️ Config-Driven | หลายโมดูลอ่านค่าเริ่มต้นจากไฟล์ JSON ผ่าน `storage.config_mgr` |
| 🛡️ Graceful Degradation | พลาด dependency ไม่แครช มี fallback เสมอ |
| 🔌 Lazy Initialization | ฮาร์ดแวร์ถูกสร้างเมื่อเรียกใช้จริง คืนทรัพยากรด้วย `deinit()` |
| 📝 Emoji-Prefixed Log | สถานะการทำงานแสดงผลด้วย Emoji อ่านง่าย |

## ลำดับการใช้งานที่แนะนำ

1. เชื่อมต่อเน็ตเวิร์กด้วย `network` (WiFi / Ethernet)
2. อ่านค่าจาก `sensors`
3. แสดงผลหรือสั่งงานผ่าน `display` / `output`
4. ส่งข้อมูลด้วย `mqtt` / `http` / `cloud`
5. บันทึกข้อมูลผ่าน `storage`
6. ดูแลระบบด้วย `system`

> หมายเหตุ: เอกสารในคู่มือนี้ **อัปเดตจากโค้ดจริงใน `src/lib`** — บางหมวด README เดิมของ lib เขียน API ไว้ล่วงหน้าที่ไม่ตรงกับโค้ดจริง ข้อมูลในเว็บนี้จึงเป็นแหล่งอ้างอิงที่ตรงกับโค้ดที่สุด

## ภาพรวมและแนวคิดการใช้งาน

`p10` เป็นชุดไดรเวอร์สำหรับ **P10 LED Panel** (บอร์ดจอป้ายขนาดใหญ่ 32x16) ที่ใช้หัวต่อ **HUB75** ประกอบด้วย 3 ชั้น:

| ไฟล์ | บทบาท |
|---|---|
| `p10_hub75.py` | `HUB75Engine` — ส่งข้อมูลไป panel ผ่าน GPIO + RMT (timing ระดับ µs) |
| `p10_buffer.py` | `MonoBuffer` / `RGBBuffer` — frame buffer (1-bit / 24-bit) + ฟอนต์ |
| `p10_display.py` | `P10Mono` / `P10RGB` / `P10Chain` — API ระดับสูง (เหมือนไดรเวอร์ display อื่น) |

```python
import sys
sys.path.append('/lib')
from p10 import P10Mono, P10RGB, RED, GREEN, BLUE
from p10.p10_hub75 import HUB75Engine
from p10.p10_buffer import MonoBuffer, RGBBuffer
```

**Scan modes:** `SCAN_4` (32×16, ขา A,B), `SCAN_16` (64×32, A,B,C,D), `SCAN_32` (64×64, A,B,C,D,E)

**Pin map อัตโนมัติตามบอร์ด** (`pins=None`): ใช้ `PINS_C3` (GPIO 0-10, 20-21) หรือ `PINS_S2` (GPIO 1-14) — ระบุเองได้ผ่าน argument `pins={"R1": 0, ...}`

## P10Mono — แผงขาวดำ

`P10Mono(width=32, height=16, scan=None, pins=None, clk_freq=10000000, refresh_hz=120)`
- `scan=None` → อัตโนมัติ `height // 2`
- สี: `ON=1`, `OFF=0`

| method | ใช้ตอนไหน |
|---|---|
| `fill(value=1)` / `clear()` | เติม / ล้าง |
| `pixel(x, y, value=1)` / `get_pixel(x, y)` | จุด |
| `hline` / `vline` / `rect` / `fill_rect` | เส้น/สี่เหลี่ยม |
| `text(s, x, y, value=1)` / `center_text(s, y)` | ข้อความ (ฟอนต์ 3x5) |
| `scroll_text(s, delay_ms=80)` | เลื่อนข้อความ (blocking demo) |
| `show()` | **ส่ง buffer ไปจอ** (ต้องเรียก) |
| `brightness(level)` | ความสว่าง 0–255 |
| `on()` / `off()` | เปิด/ปิด |
| `start_refresh()` / `stop_refresh()` | auto-refresh ผ่าน `machine.Timer` (ใช้กับ animation) |
| `deinit()` | คืนทรัพยากร |

```python
panel = P10Mono(width=32, height=16)
panel.text("Hi", 0, 2)
panel.show()
```

## P10RGB — แผงสี (24-bit)

`P10RGB(width=32, height=16, scan=None, pins=None, clk_freq=10000000, refresh_hz=60, bcm=True)`
- `bcm=True` → Bit Correction Modulation (สีจริง 16M สี แต่ refresh ช้าลง)
- `bcm=False` → fast mode (8 สี, refresh เร็ว)
- สี: ค่าคงที่ `BLACK, WHITE, RED, GREEN, BLUE, YELLOW, CYAN, MAGENTA, ORANGE` (tuple RGB)

method ชุดเดียวกับ P10Mono แต่รับ `color` tuple แทน `value` (`fill(color)`, `pixel(x,y,color)`, `text(s,x,y,color)`, `center_text(s,y,color)`)

```python
panel = P10RGB(width=32, height=16)
panel.fill(BLACK)
panel.pixel(10, 5, RED)
panel.fill_rect(0, 0, 8, 8, BLUE)
panel.show()
```

ข้อควรระวัง: `P10RGB.text()` วาดช้าพอสมควร (สร้าง temp MonoBuffer แล้ว copy ทีละ pixel) — ไม่เหมาะข้อความที่อัปเดตถี่ๆ

## P10Chain — ต่อพ่วงหลายแผง

`P10Chain(panel_w=32, panel_h=16, scan=None, chain_h=1, chain_v=1, pins=None, clk_freq=10000000, refresh_hz=60)`
- `chain_h`/`chain_v` = จำนวนแผงแนวนอน/แนวตั้ง (เช่น 2×1 = 64×16)
- วาดลง buffer เสมือน (กว้าง `panel_w × chain_h`, สูง `panel_h × chain_v`)

method เหมือน P10Mono (`fill, clear, pixel, text, center_text, hline, vline, rect, fill_rect, show, brightness, on, off, start_refresh, stop_refresh, deinit`)

```python
panel = P10Chain(panel_w=32, panel_h=16, chain_h=2, chain_v=1)
panel.text("Hello World!", 0, 4)
panel.show()
```

⚠️ **ข้อจำกัดที่เห็นในโค้ด:** `P10Chain.show()`/auto-refresh ยังส่ง **buffer placeholder ว่าง** (ไม่ได้แมปข้อมูลจริงลงแผง) — ปัจจุบันยังไม่แสดงผลจริงบนจอ ใช้ได้เฉพาะแก้ภาพอนิเมชันในสเกลเล็ก/รอปรับปรุง

## Low-level: HUB75Engine

`HUB75Engine(scan=SCAN_4, rgb=True, pins=None, clk_freq=10000000)` — ใช้เมื่อต้องการควบคุมเอง
- `init()` / `deinit()`, `brightness(0-255)`, `scan_mode`, `is_rgb`, `total_rows`
- `show_mono(buf, width)` — buffer 1-bit
- `show_rgb(buf, width)` — BCM (RGB888), `show_rgb_fast(buf, width)` — 8 สี
- `show_rgb_chain(buf, panel_width, chain_h, chain_v)`
- ถ้า `machine.RMT` init ไม่ได้ จะ fallback เป็น GPIO bit-bang (ช้าลง)

## Buffer: MonoBuffer / RGBBuffer

`MonoBuffer(width, height)` — 1 bit/pixel; `RGBBuffer(width, height)` — 3 bytes/pixel
- property `buffer` → `bytearray` ส่งให้ engine
- วาด: `fill/clear/pixel/get_pixel/hline/vline/rect/fill_rect/row/char/text/center_text/scroll_text`
- ฟอนต์ 3x5 (`_CHAR_W=3`, `_CHAR_H=5`) รองรับ A-Z, 0-9, `!.:-_/#*`
- `color_rgb(r, g, b)` ฟังก์ชันสร้าง tuple สี; ค่าคงที่สีใน `p10_buffer` มีเพิ่ม: `PURPLE`, `DIM`
- ⚠️ `RGBBuffer.text()` เป็น `pass` (ยังไม่ implement) — ใช้ `P10RGB.text()` แทน

## การต่อวงจร (HUB75 → ESP32)

```
P10 Panel          ESP32-C3 (default)
─────────          ────────────────
R1, G1, B1      →  GPIO 0, 1, 2     (ครึ่งบน)
R2, G2, B2      →  GPIO 3, 4, 5     (ครึ่งล่าง)
A, B, C, D, E   →  GPIO 6, 7, 8, 9, 10
CLK             →  GPIO 20
LAT (STB)       →  GPIO 21
OE              →  GPIO 10 (reuse กับ E ถ้า 1/4 scan)
GND             →  GND
```

ข้อควรระวัง: แผง P10 ต้องใช้ **ไฟ 5V แยก** (กินกระแสสูง) — ESP32 ส่งสัญญาณ logic 3.3V ได้ (RMT/GPIO ทำงาน) แต่ควรตรวจ spec แผง; GPIO 10 ซ้ำกันระหว่าง E และ OE ตาม comment ในโค้ด

## ใช้ร่วมกับ

- `output` — ควบคุมป้ายร่วมกับมอเตอร์/relay
- `cloud` / `mqtt` — รับข้อความมาแสดงบนป้าย
- `system` — แสดงเวลา/สถานะ
- `display` — ไดรเวอร์อื่นใช้รูปแบบ API เดียวกัน (`fill/text/show`) ทำให้ย้ายโค้ดระหว่างจอได้
